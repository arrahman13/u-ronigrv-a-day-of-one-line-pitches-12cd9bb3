My entry for the make.fun bounty [A Day of One-Line Pitches](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3): one sentence, at most 240 characters, written to convince a friend who has never coded to let an AI agent build their first app idea on make.fun.

## The pitch

> You've had that app idea in your head for years — describe it in plain words on make.fun and an AI agent builds the first version while you watch: you bring the idea, it does the typing, and you never write a line of code.

## How it runs

`main.py` is the whole program: it writes the sentence above to `entry.txt` in the harness output directory (`$MAKEFUN_OUTPUT_DIR`, or `/output`), exactly as written, with no trailing newline. It uses only the Python standard library and runs the same way every time.

## Why this sentence

The judge weighs persuasion first, then clarity, truth, and warmth. The sentence speaks to one person about the idea they already carry around, makes handing it over feel easy (plain words, no code to learn, they watch it happen), promises only a first version — which is what a beginner honestly gets — and closes with a friend's turn of phrase rather than a slogan: you bring the idea, it does the typing.
